Consulta I

Onde é mais barato — e mais caro

Escolha um combustível para ver o menor e o maior preço registrados no semestre, com o posto, o endereço, o bairro e a data da coleta.

Ver o SQL desta consulta 
WITH base AS (
    SELECT c.tipo,
           p.nome     AS posto,
           CONCAT(p.logradouro, ', ', p.numero) AS endereco,
           p.bairro,
           pc.valor,
           co.data_coleta,
           ROW_NUMBER() OVER (PARTITION BY c.id_combustivel
                              ORDER BY pc.valor ASC,  co.data_coleta ASC) AS rn_menor,
           ROW_NUMBER() OVER (PARTITION BY c.id_combustivel
                              ORDER BY pc.valor DESC, co.data_coleta ASC) AS rn_maior
    FROM preco_coletado pc
    JOIN coleta      co ON co.id_coleta     = pc.id_coleta
    JOIN posto       p  ON p.id_posto       = co.id_posto
    JOIN combustivel c  ON c.id_combustivel = pc.id_combustivel
)
SELECT tipo,
       CASE WHEN rn_menor = 1 THEN 'MENOR' ELSE 'MAIOR' END AS extremo,
       posto, endereco, bairro, valor, data_coleta
FROM base
WHERE rn_menor = 1 OR rn_maior = 1
ORDER BY tipo, extremo;
Consulta II

Preço médio por posto

Escolha um combustível para ver, em cada posto, a média de todas as coletas do semestre e quantas amostras sustentam essa média.

Ver o SQL desta consulta 
SELECT p.nome                  AS posto,
       p.bairro,
       c.tipo,
       ROUND(AVG(pc.valor), 3) AS preco_medio,
       COUNT(*)                AS qtd_amostras
FROM preco_coletado pc
JOIN coleta      co ON co.id_coleta     = pc.id_coleta
JOIN posto       p  ON p.id_posto       = co.id_posto
JOIN combustivel c  ON c.id_combustivel = pc.id_combustivel
GROUP BY p.id_posto, p.nome, p.bairro, c.id_combustivel, c.tipo
ORDER BY p.nome, c.tipo;
Consulta III

Preço mais recente

Escolha um combustível para ver o último valor coletado em cada posto — o retrato mais atual da base.

Ver o SQL desta consulta 
WITH ranked AS (
    SELECT p.nome AS posto, p.bairro, c.tipo, pc.valor, co.data_coleta,
           ROW_NUMBER() OVER (PARTITION BY p.id_posto, c.id_combustivel
                              ORDER BY co.data_coleta DESC) AS rn
    FROM preco_coletado pc
    JOIN coleta      co ON co.id_coleta     = pc.id_coleta
    JOIN posto       p  ON p.id_posto       = co.id_posto
    JOIN combustivel c  ON c.id_combustivel = pc.id_combustivel
)
SELECT posto, bairro, tipo, valor, data_coleta
FROM ranked
WHERE rn = 1
ORDER BY posto, tipo;
Consulta IV

Evolução do preço no tempo

Escolha um combustível e um posto para ver o preço coleta a coleta ao longo do semestre.

—

Ver o SQL desta consulta 
SELECT p.nome AS posto,
       p.bairro,
       c.tipo,
       pc.valor,
       co.data_coleta
FROM preco_coletado pc
JOIN coleta      co ON co.id_coleta     = pc.id_coleta
JOIN posto       p  ON p.id_posto       = co.id_posto
JOIN combustivel c  ON c.id_combustivel = pc.id_combustivel
WHERE p.cnpj = '03.948.877/0003-69'   -- posto escolhido acima
  AND c.tipo = 'GASOLINA'             -- combustivel escolhido acima
ORDER BY co.data_coleta;
